## 一天中的世界

默认 AUTO，每次访问均读取设备本地 `new Date()`。不访问定位，也不假设汪意所在地。设备时钟及其时区决定画面。

| 本地时间 | 状态 |
| --- | --- |
| 05:00–08:00 | 清晨：柔光、薄雾、露水 |
| 08:00–16:30 | 白昼：蓝天、分层白云、草地 |
| 16:30–18:30 | 黄昏：渐暖天空、低太阳、长阴影 |
| 18:30–21:00 | 入夜：暮色、星星、窗灯 |
| 21:00–次日 05:00 | 深夜：独立夜景、月光、星云、少量萤火虫 |

颜色、太阳 / 月亮位置、草地和云亮度、灯光、星空等在数值关键帧之间连续插值；标签边界不触发整幅图片硬切。昼夜地形是两张构图对应的原创绘画，按插值比例混合。太阳路径属于美术化的本地时间表现，不是实际天文日出日落计算。

左下太阳 / 月亮按钮可预览五个时段，约 2.4 秒平滑过渡；选择 AUTO 回到当前设备时间。预览状态不保存。首次开场 2.1 秒，可跳过；后续访问缩短为 0.7 秒，仅在本机保存一个访问标记。

点击导航、滚轮、触控、浏览器前进 / 后退沿同一镜头路径移动，依次经过纸条、树下悬挂相册、野餐角落、木屋窗边和安静山坡。邻近旅程约 0.9 秒，较远约 1.3–1.7 秒，Logo 返回约 1–1.4 秒；途中可随时改道或滚动接管。前景树叶 / 窗帘短暂经过镜头，数字、标题与内容分层出现。支持直接打开和刷新 #gallery、#notes 等位置。

照片展开时移动的就是原来的整张拍立得及其图片节点，关闭后回到当前屏幕尺寸对应的原槽；保留前后按钮、方向键、手机横滑、Escape、背景关闭与焦点返回。笔记本在窗边原位展开、翻页、合上，镜头额外推进约 6.5%；离开窗边自动合本。

## 季节、天气与小猫

四季由同一世界状态管理。AUTO 按设备当前月份采用北半球美术季节：3–5 月春、6–8 月夏、9–11 月秋、12–2 月冬；可手动预览，季节变化约 12 秒。冬景包含原构图的雪坡、积雪屋檐和树枝，昼夜仍连续混合。

天气是虚构风景的模拟天气，不读取定位或天气接口。晴、多云、雨、雪之间约 45 秒渐变；自动天气通常隔 10–15 分钟再变化。雨天进入窗边，窗滴与檐滴逐渐出现；主动开启的雨声会平滑变柔。导航不会重置天空、云、风、季节或天气。

一只原创小猫始终留在同一片草坡，独立在睡眠和轻微苏醒之间变化；它不会因为换栏目而出现在另一处，也不表示汪意实际养猫。

## 声音、动效与性能

声音默认关闭，只在主动点击后创建音频上下文；用本地 Web Audio 合成很轻的风、草叶与鸟声 / 虫鸣，无配乐和外部音源。关闭视觉动效不禁止已主动开启的声音。切到后台暂停渲染与声音，回来后声音保持关闭。

尊重系统 `prefers-reduced-motion`，也可用“动效开 / 关”暂停环境动效。静态模式仍更新本地时间、支持全部阅读交互；导航使用约 260 毫秒短淡入和小位移，关闭大幅镜头、视差、花瓣和复杂翻页。设备不可见时停止视觉帧循环；回来重新读取真实时间，不补播错过的环境事件。

桌面使用三层缓慢云、轻微指针视差和稀疏 Canvas。手机保留两层动态云，降低像素比、粒子数和环境绘制频率，关闭复杂背景模糊，不请求陀螺仪权限。草 / 花 / 叶响应有错开的相位，阵风每 30–90 秒携带少量花瓣；鸟和夜间流星均为低频随机事件。
