# yi.wang · 汪意的个人小世界

在 yi.wang 当前奶油手账版源文件上修改，继续使用奶油白、蜜桃粉、浅鼠尾草绿，以及原有纸卡、拍立得、胶带、小花和便签。

纯 HTML / CSS / JavaScript，没有框架、构建步骤、后端或字体 CDN。按要求保留 Umami 统计脚本；页面样式与交互由本地文件提供。

## 已定稿的内容

- 首页小字：`YI.WANG`
- 首页主标题：`汪意`
- 首页副文案：`网页由文杰维护`
- 页脚：`yi.wang · maintained by 郑文杰`
- 栏目顺序：最近 · 相册 · 小东西 · 随便写写 · 关于

原双人介绍、故事时间线和信封结尾已替换。没有添加人物经历、具体日期、真实照片、科研信息、地点或个人介绍；未提供的内容均保留方括号占位符。

本次排版优化收紧了章节留白，统一纸卡阴影与边缘，增加浅色纸纹，提升副文案可读性；平板宽度下将两个相框放到标题纸卡下方，避免遮挡。

## 以后填写真实内容

| 内容 | 编辑位置 |
| --- | --- |
| 最近 | `index.html` 中的 `【修改最近】`：替换日期、记录标题和记录内容；可增删完整 `article` |
| 相册 | `script.js` 中的 `PHOTOS`：填写 `src`、可选高清图 `full`、说明 `caption`、日期 `date`、地点 `place`；首页相框同步使用前两张 |
| 相册说明 | `index.html` 中的 `[相册说明]` |
| 小东西 | `index.html` 中的 `【修改小东西】`：填写类别、图片、名称和说明；拿到真实网址后，将 `[链接待添加]` 的 `span` 替换成带 `href` 的 `a` |
| 随便写写 | `index.html` 中的 `【修改随便写写】`：替换文字和日期；可增删完整 `article` |
| 个人介绍 | `index.html` 中的 `【修改个人介绍】`：只有收到介绍内容后才替换占位符 |
| 可选背景与音乐 | `script.js` 开头的 `BACKGROUND` 和 `MUSIC_SRC`，留空保持当前效果 |

照片和音频放入 `assets`，填写大小写一致的相对路径，例如 `assets/photo-01.jpg`。缺少具体内容的字段可继续保留占位符；不需要展示的日期或地点也可以填空字符串。替换 HTML 文本时，`&`、`<`、`>` 分别写成 `&amp;`、`&lt;`、`&gt;`。

当前没有预置照片或配乐。音乐初始关闭，只有点击后才尝试播放；没有音源时提示“尚未添加音乐”。小东西的空链接为普通文字，不会出现点了没反应的假按钮。

## 保留的交互

- 自然滚动、阅读进度、章节定位和手机目录。
- 相册放大、前后按钮、左右方向键、单指横滑、Escape / 关闭按钮 / 背景关闭；关闭后焦点回到打开它的按钮。
- 首页相框跳转相册，并与相册前两张照片共享来源。
- 动效开关，尊重系统“减少动态效果”；音乐可选、默认关闭、切到后台暂停。
- JavaScript 关闭时，所有正文仍可通过滚动阅读。
