# yi.wang · 奶油手账版

基于你上传的 `yi-wang-website.zip` 修改视觉与布局。原版保留不动。

## 这一版改了什么

奶油白纸张、蜜桃粉、浅鼠尾草绿和柔黄配色；暖棕文字。
首页是贴着胶带的纸卡和相框，关于页是小册子与姓名纸签，
照片墙是错落的拍立得，故事使用纸片与花朵虚线，手记是便签信纸，结尾是信封。
小花、叶子、云朵、胶带、相机图标全部由 CSS 和页面内 SVG 绘制。
它们仅是装饰，不代表真实照片、地点或经历。

没有代填姓名、关系、日期、照片、照片说明、故事或信件。
章节序号 01—06 只表示网页章节，不是纪念日或相处天数。
没有默认音乐、视频、真实照片，也没有自动计算纪念日。

## 本地打开

全部解压到一个文件夹，然后双击 `index.html`。
请让 `index.html`、`styles.css`、`script.js` 和 `assets` 留在同一文件夹内。
无需 npm、Node.js、数据库、后端或构建命令。

## 替换内容

在文件里搜索以下标记：

| 标记 | 文件 | 修改位置 |
| --- | --- | --- |
| 【修改首页文字】 | index.html | 首页三行文字；同时修改 title、description、页眉与返回首页的无障碍名称 |
| 【修改人物信息】 | index.html | 两个人的姓名与文字；A / B 圆形标记只是版式占位 |
| 【修改日期】 | index.html / script.js | 日期占位符；只填写你提供的日期 |
| 【修改照片】 | script.js / index.html | 六张画廊照片在 PHOTOS 中填写；故事照片按 HTML 注释替换 |
| 【修改故事】 | index.html | 日期、故事、正文、地点；可复制或删除完整 article |
| 【修改背景图片/视频】 | script.js | BACKGROUND 默认留空，使用奶油底色；可自选本地图片或静音视频 |
| 【修改音乐】 | script.js | MUSIC_SRC 默认留空，点击会提示“尚未添加音乐” |
| 【修改结尾】 | index.html | 信纸内的网站名称与结尾文字 |
| 【修改配色】 | styles.css | 顶部 :root 颜色变量；更深入调整可按章节注释查找 |

手记正文与日期直接修改 `index.html` 里的 `.note-card`。

照片放入 `assets`，例如 `assets/photo-01.jpg`；然后在 `PHOTOS` 中填 `src`。
`full` 可填高清版本，`caption` / `date` / `place` 是照片说明、日期和地点。
首页两张相框自动使用 PHOTOS 的前两张照片；没有填写时显示 `[照片]`。
不请求第三方示例图。不同设备的系统字体可能略有差别。

## 已保留的功能

自然滚动、章节定位、移动端目录、照片放大、左右切换、方向键、触屏横滑、
Escape 关闭、焦点返回、系统减少动态效果与手动动效开关。
音乐默认关闭，不保存开启状态，切到后台会暂停。
本版只有少量花朵轻摆与云朵移动，没有爱心雨、鼠标拖尾或粒子系统。

本次只交付网站文件，未代替你更新仓库或操作线上网站。
“私人”仅描述用途；该静态网站没有登录或访问权限控制。
不要在公开仓库里放密码、工作机密或不愿公开的资料。

## 文件

- index.html：网页结构和文字占位符
- styles.css：新的奶油手账视觉
- script.js：配置、相册、导航、动效与音乐控制
- .nojekyll：保留原项目的静态部署辅助文件
- assets/：留给你的照片、音乐、视频

原版深色水面图已从本版压缩包移除，不影响原 ZIP。
